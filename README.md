
# Agent Development Kit
## An open-source AI agent framework integrated with Gemini and Google

#### Easiest way to create agent, multi-agents, tools, Session State for Memory:..and many more which you are looking

#### you can use any model

#### Deploye anywhere


Thanks to [ADK Documentation](https://google.github.io/adk-docs/)


Examples : 

weather based tool with agent

    RUN with terminal
    1. cd multi_tool_agent folder
    2. rename .env_sample to .env. & set set key
    3. adk run multi_tool_agent

    RUN in web
    1. cd multi_tool_agent folde
    2. rename .env_sample to .env. & set key
    3. adk web 


streaming based : to enable audio and video communication with it

    here "google_search" being used as a tool

    1. cd adk-streaming
    2. rename .env_sample to .env. & set key
    3. adk web
